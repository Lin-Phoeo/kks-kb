Name of the label. Labels can be created with the MakeLabel command, and then jumped to with the JumpToLabel command.\nJumping to a label immediately moves playback cursor over the first MakeLabel keyframe with that label name that satisfies its condition (if MakeLabel has a condition that fails, the search continues). If no valid labels are found the jump is ignored.=标签的名称。用 MakeLabel 命令创建标签，再用 JumpToLabel 跳转。\n跳转会立即把播放指针移到首个名称相同且满足条件的 MakeLabel 关键帧；若其条件不成立，会继续查找。没有有效标签时忽略跳转。
Name of the variable. Variables can be used in conditions and as values of most commands.\n\nVariables don't have to be defined before use, every variable has a value of 0 by default.\n\nVariable values are NOT reset when stopping playback! If you need to reset a variable, add commands at the start to set it to 0.=变量名称，可用于条件和多数命令的值。\n\n变量无需预先定义，默认值均为 0。\n\n停止播放时不会重置变量值！若需重置变量，请在开头添加将它设为 0 的命令。
