<b>Layout & scaling</b>=<b>布局与缩放</b>
• Saved <b>anchor-relative</b> position and rotation vs the character guide at save time.\n• On load, position and item scale adjust for the character’s current <b>Studio object scale</b> and <b>body height</b> (same ratio logic as group relative positions).\n• Items saved on a <b>body part</b> store a workspace tree path and Studio <b>changeAmount</b> attach offsets (v5 TSV). Default load reparents via the tree; <b>Load as free</b> uses the same world layout without parenting.\n• ⚠ <b>Yellow</b> banner — selected character does not have this pose applied (save/load still work). Orange ⚠ on a row — last load warning (e.g. body part not found).=• 记录相对于保存时角色控制柄的<b>锚点相对</b>位置和旋转。\n• 加载时按角色当前的<b>Studio 物件缩放</b>与<b>身高</b>调整位置和物件缩放，使用与分组相对位置相同的比例逻辑。\n• 挂接在<b>身体部位</b>的物件保存工作区树路径与 Studio <b>changeAmount</b> 挂接偏移（v5 TSV）。默认加载会恢复父子关系；<b>作为独立物件加载</b>保持相同世界布局但不设父级。\n• ⚠ <b>黄色</b>提示表示角色未应用此姿势，仍可保存／加载；行上的橙色 ⚠ 表示上次加载警告，例如找不到身体部位。

<size\=17><b>Pose groups</b></size>=<size\=17><b>姿势分组</b></size>
A <b>pose group</b> is a named set of library poses that stay together in the grid, share optional <b>group tags</b>, and can be exported/imported inside v5 ZIP packs (v2–v4 packs still import; layout fields optional). 1. Select <b>two or more ungrouped</b> poses in the bottom bar (checkboxes or thumbnail selection).=1. 在底部操作栏选择<b>至少两个未分组</b>姿势，可用复选框或缩略图。
2. Click <b>Group…</b>, enter a name, confirm.=2. 点击<b>分组…</b>，输入名称并确认。
3. To add poses later, select ungrouped poses + at least one member of the target group, then <b>Group…</b> again (merges into the existing group when applicable).=3. 要添加姿势，选择独立姿势和目标组至少一个成员，再点击<b>分组…</b>；适用时会并入现有组。
4. <b>Ungroup</b> removes selected poses from their groups (does not delete pose files).=4. <b>取消分组</b>将选中姿势移出分组，不删除姿势文件。
5. <b>Rename…</b> / <b>Tags…</b> / <b>Export…</b> appear on the <b>group action bar</b> when the group header is selected as a group entity.=5. 将分组标题作为实体选中后，<b>分组操作栏</b>会显示<b>重命名…</b>／<b>标签…</b>／<b>导出…</b>。
<b>Relative positions (save & apply)</b>=<b>相对位置（保存与应用）</b>
Optional layout when a group is applied multi-character. Everything is keyed by <b>pose path</b> and <b>assignment order</b> from <b>Chars</b> priority (grid display order) — not by which Studio character card you used at save time.=用于多角色应用分组的可选布局。以<b>姿势路径</b>及<b>角色</b>优先级对应的<b>分配顺序</b>（网格显示顺序）为依据，不绑定保存时使用的角色卡。
<b>Anchor (first pose)</b>=<b>锚点（第一个姿势）</b>
• The <b>first pose</b> in display order is the anchor.=• 显示顺序中的<b>第一个姿势</b>是锚点。
• At save: anchor world position + body height are recorded on that pose path.=• 保存时：记录该姿势路径对应的锚点世界位置和身高。
• At apply: anchor character is <b>not moved</b> by layout; other characters use <b>anchor position + anchor rotation × saved local offset</b> (orbit with anchor).=• 应用时：锚点角色<b>不会移动</b>，其他角色使用<b>锚点位置 + 锚点旋转 × 已保存局部偏移</b>，随锚点旋转。
<b>Requirements to enable Save positions…</b>=<b>启用“保存位置…”的条件</b>
• Not during import preview.=• 不处于导入预览。
• The group was the <b>last</b> thing you applied with <b>Apply to characters…</b> — no other pose applied since.=• 该组是<b>最近一次</b>通过<b>应用到角色…</b>应用的内容，之后未应用其他姿势。
• Studio selection: <b>exactly as many characters as poses</b> in the group.=• Studio 选中的<b>角色数量与分组姿势数量完全相同</b>。
• <b>One-to-one gender match</b> via <b>Chars</b> lists and pose tags (see <b>Multi-character apply</b>).=• 通过<b>角色</b>列表与姿势标签实现<b>性别一一匹配</b>，参见<b>多角色应用</b>。
<b>Workflow — save</b>=<b>保存流程</b>
1. Set up <b>Chars</b> and pose tags if needed.=1. 按需设置<b>角色</b>和姿势标签。
2. Select characters in Studio → apply group → arrange scene.=2. 在 Studio 选择角色 → 应用分组 → 布置场景。
3. <b>Save positions…</b> stores per other pose: local <b>offset</b> and <b>rotation</b> vs anchor, plus <b>body height</b> on every pose path.=3. <b>保存位置…</b>记录其他姿势相对锚点的局部<b>偏移</b>与<b>旋转</b>，以及每个姿势路径的<b>身高</b>。
<b>Workflow — apply</b>=<b>应用流程</b>
Same apply path and assignment order. After poses are applied:=使用相同的应用入口和分配顺序。应用姿势后：
• <b>Apply relative positions</b> (global) — <b>anchor + rotated offset</b> (orbits with anchor) and relative rotation on each non-anchor pose.=• 全局<b>应用相对位置</b>为非锚点姿势应用<b>锚点 + 旋转后的偏移</b>及相对旋转。
• <b>Adjust for body height</b> (global; requires relative positions) — same full offset, but <b>offset.y</b> is scaled from saved vs current body-height ratios on each pose path (no hardcoded world multiplier).=• 全局<b>按身高调整</b>需要先启用相对位置，保留完整偏移，但按保存／当前身高比例缩放 <b>offset.y</b>，不使用硬编码世界倍数。
• <b>Clear positions</b> — removes offsets and heights for that group.=• <b>清除位置</b>移除该组的偏移与身高数据。
<b>Group thumbnails</b>=<b>分组缩略图</b>
Capture preview images for <b>every pose in a group</b> while characters stay posed together in the scene.=保持场景角色一起摆姿，为<b>组内每个姿势</b>捕获预览图。
<b>When Group thumbnails… is enabled</b>=<b>启用“分组缩略图…”的条件</b>
• Select the <b>group header</b> (group entity, not individual member checkboxes).=• 选择<b>分组标题</b>，即分组实体，而非成员复选框。
• Select <b>exactly as many characters in Studio as poses</b> in the group.=• Studio 选中的<b>角色数必须恰好等于姿势数</b>。
• Characters must match pose genders and <b>Chars</b> priority (same one-to-one rules as multi-character apply).=• 角色应匹配姿势性别与<b>角色</b>优先级，遵循多角色应用的一一分配规则。
• Not during import preview; not while another capture overlay is open.=• 不在导入预览或其他捕获浮层已打开时使用。
<b>What happens</b>=<b>执行过程</b>
1. All group poses are applied at once (including relative layout when <b>Apply relative positions</b> / height / object-scale toggles are on — same as <b>Apply to characters…</b>).=1. 一次应用所有分组姿势；启用<b>应用相对位置</b>／身高／物件缩放时，也会应用对应布局，与<b>应用到角色…</b>相同。
2. The capture overlay opens; frame the shot with the green square (drag / resize).=2. 打开捕获浮层，拖动／缩放绿色方框调整取景。
3. For each pose in display order, characters on <b>other</b> poses use Studio <b>simple color</b> (monocolor) so the thumbnail highlights one character.=3. 按显示顺序处理各姿势，<b>其他</b>姿势的角色使用 Studio <b>单色显示</b>，仅目标角色保留完整细节。
4. <b>Capture</b> writes that pose's PNG; <b>Skip</b> skips it; <b>Auto-capture</b> finishes the rest automatically; <b>Cancel</b> exits and restores normal rendering.=4. <b>捕获</b>写入该姿势 PNG；<b>跳过</b>跳过当前项；<b>自动捕获</b>完成剩余项；<b>取消</b>退出并恢复正常渲染。
Example: two-pose group, characters A and B — A gets pose 1, B gets pose 2. While capturing pose 1, B is monocolor; while capturing pose 2, A is monocolor.=例如两姿势组中的角色 A、B：A 分配姿势 1，B 分配姿势 2。捕获姿势 1 时 B 单色显示，捕获姿势 2 时 A 单色显示。
<b>Two kinds of selection</b>=<b>两种选择方式</b>
<b>Group entity</b> — click the <b>group header</b> (▦ row). Highlights the segment; shows the group bar (rename, tags, export, apply, <b>Group thumbnails…</b>, save/clear positions, <b>Apply relative positions</b>, <b>Adjust for body height</b>). Ctrl+click toggles group entities; Shift+click range-selects group headers in the filtered list.=<b>分组实体</b>：点击<b>分组标题</b>（▦ 行），高亮区段并显示操作栏，包括重命名、标签、导出、应用、<b>分组缩略图…</b>、保存／清除位置、<b>应用相对位置</b>、<b>按身高调整</b>。Ctrl+点击切换分组选择，Shift+点击在筛选列表中范围选择标题。
<b>Pose members</b> — checkboxes / thumbnail clicks on cards inside the segment. Used for move, copy, delete, tag selected, partial export, etc.=<b>姿势成员</b>：使用区段内卡片复选框／缩略图选择，用于移动、复制、删除、标签及部分导出等。
During <b>import preview</b>, clicking the group header toggles <b>all member checkboxes</b> for import (not group-entity mode).=<b>导入预览</b>时点击分组标题，会切换<b>全部成员复选框</b>，不进入分组实体选择。
<b>Group tags vs pose tags</b>=<b>分组标签与姿势标签</b>
• <b>Group tags</b> — edited via <b>Group tags…</b>; used for <b>filtering</b> (include/exclude in the tag window) and shown on the group header.\n• <b>Pose tags</b> — per-card tags (e.g. <b>Male</b> / <b>Female</b> for multi-character apply).\n• <b>Exclude</b> filters: ungrouped poses with an excluded tag are hidden; inside a visible group <b>all members stay</b> but cards with excluded pose tags are <b>dimmed</b> and tag names show in <b>red</b>.=• <b>分组标签</b>通过<b>分组标签…</b>编辑，用于标签窗口的<b>筛选</b>，并显示在组标题上。\n• <b>姿势标签</b>属于单张卡片，例如多角色应用用到的 <b>Male</b>／<b>Female</b>。\n• <b>排除</b>筛选会隐藏独立姿势；在可见分组中<b>保留所有成员</b>，但被排除的卡片会<b>变暗</b>，标签名显示为<b>红色</b>。
<b>Grid layout</b>=<b>网格布局</b>
Grouped poses render in a bordered block. Large groups may continue on the next row (continuation header without repeating tags). Sort order applies to <b>groups as blocks</b> and to ungrouped poses.=分组姿势在带边框的块中显示。较大分组可延续到下一行，续行标题不重复标签。排序作用于<b>整个分组块</b>及独立姿势。
<b>Move / copy / delete</b>=<b>移动／复制／删除</b>
• <b>Move…</b> / <b>Copy…</b> — works on ungrouped poses, or when exactly <b>one full group</b> is selected (all members). The whole group moves/copies together.\n• <b>Delete…</b> — can remove group members or entire groups per confirmation.\n• <b>Export…</b> — include group metadata (<b>memberRelativeOffsets</b>, <b>memberBodyHeights</b> when saved) when every member of a group is selected, or use <b>Export…</b> from the group bar.=• <b>移动…</b>／<b>复制…</b>用于独立姿势，或恰好选中<b>一个完整分组</b>时；整组一起移动／复制。\n• <b>删除…</b>按确认内容移除成员或整组。\n• <b>导出…</b>在整组选中时包含已保存的分组元数据（<b>memberRelativeOffsets</b>、<b>memberBodyHeights</b>），也可用组操作栏的<b>导出…</b>。
<b>Import / export (ZIP v5)</b>=<b>导入／导出（ZIP v5）</b>
v3+ packs include <b>groups[]</b> in <b>metadata.json</b>; v4 adds <b>memberRelativeOffsets</b>; v5 adds <b>memberBodyHeights</b> (parallel to members). On import preview, groups appear as segments; layout imports when present. v2 packs without groups still import as flat poses.=v3+ 包在 <b>metadata.json</b> 中包含 <b>groups[]</b>；v4 加入 <b>memberRelativeOffsets</b>；v5 加入与成员对应的 <b>memberBodyHeights</b>。导入预览按分组显示，存在布局时一并导入。不含分组的 v2 包仍可作为独立姿势导入。
<size\=17><b>Pose stash</b></size>=<size\=17><b>姿势暂存</b></size>
The <b>pose stash</b> is a temporary clipboard for character FK/IK poses. It does <b>not</b> write to <b>UserData/studio/pose</b> and is separate from <b>History</b> (automatic undo snapshots per character).=<b>姿势暂存</b>是 FK（正向运动学）／IK（逆向运动学） 姿势的临时剪贴板，<b>不会</b>写入 <b>UserData/studio/pose</b>，与按角色自动记录撤销快照的<b>历史</b>不同。
<b>Opening and closing</b>=<b>打开与关闭</b>
<b>Stash</b> (top bar in <b>Full</b> layout; character row in <b>List</b> / <b>Mini</b>) — toggles the stash UI. If open (docked or floating), closes it. If closed, opens in the last mode you used.=<b>暂存</b>在<b>完整</b>布局的顶部，或<b>列表</b>／<b>迷你</b>布局的角色行中。打开时再次点击会关闭；关闭时按上次使用的模式重新打开。
<b>Docked</b> — side pane beside the browser (like <b>History</b>). Closes when the main Pose Browser window closes.=<b>停靠</b>：像<b>历史</b>一样位于浏览器旁边，主姿势浏览器关闭时一起关闭。
<b>Floating</b> — use <b>Float</b> in the docked pane, or the hotkey <b>Toggle undocked pose stash</b>. Independent window: drag the title bar, resize with ◢. Stays open when the main browser is closed.=<b>浮动</b>：点击停靠面板中的<b>浮动</b>，或使用<b>切换浮动姿势暂存窗口</b>快捷键。可拖动标题栏和 ◢ 角，主窗口关闭后仍保持打开。
<b>Dock</b> on the floating window re-attaches the pane (closes the float if the browser is hidden). <b>×</b> closes only the floating stash.=浮动窗口的<b>停靠</b>会重新挂回侧面板，浏览器隐藏时则关闭浮窗；<b>×</b>只关闭浮动暂存窗口。
<b>Capture and apply</b>=<b>捕获与应用</b>
<b>Stash selected character</b> — requires <b>exactly one</b> character selected in Studio. Stores FK/IK pose data only (not world position/rotation).=<b>暂存选中角色</b>要求在 Studio 中<b>恰好选中一个</b>角色，只存 FK（正向运动学）／IK（逆向运动学） 姿势，不存世界位置／旋转。
Each entry shows <b>character name</b> and <b>timestamp</b> (newest first).=各项显示<b>角色名称</b>和<b>时间戳</b>，最新项在前。
<b>Click an entry</b> — applies that pose to <b>every</b> character currently selected in Studio (one or many).=<b>点击条目</b>将该姿势应用到当前选中的<b>所有</b>角色。
<b>Auto-delete after apply</b> — optional toggle; removes the entry after a successful apply.=<b>应用后自动删除</b>为可选开关，成功应用后移除该项。
<b>Delete</b>=<b>删除</b>
<b>x</b> on a row — confirm with <b>Yes</b> / <b>No</b>.=点击行上的 <b>x</b>，再选择<b>是</b>／<b>否</b>确认。
<b>Clear entire stash</b> — bottom of the window; confirm required.=<b>清空全部暂存</b>位于窗口底部，需要确认。
<b>Keyboard shortcut</b>=<b>快捷键</b>
Assign <b>Toggle undocked pose stash</b> in Configuration Manager → <b>Pose Browser · Keyboard shortcuts</b>. Opens or closes the <b>floating</b> stash only (works while Pose Browser is loaded, even if the main window is closed).=在配置管理器 → <b>姿势浏览器 · 快捷键</b>中设置<b>切换浮动姿势暂存窗口</b>。只控制<b>浮动</b>暂存窗口，插件加载后即使主窗口关闭也可使用。
<b>Data files</b>=<b>数据文件</b>
• <b>pose_stash.json</b> — stashed poses (base64 FK/IK blobs), auto-delete preference.\n• <b>pose_browser_options.json</b> — floating window rect and <b>docked vs float</b> preference.=• <b>pose_stash.json</b>：暂存姿势（base64 FK（正向运动学）／IK（逆向运动学） 数据）和应用后自动删除偏好。\n• <b>pose_browser_options.json</b>：浮窗矩形和<b>停靠／浮动</b>偏好。
<size\=17><b>Multi-character apply</b></size>=<size\=17><b>多角色应用</b></size>
Use this workflow when a scene has <b>several characters</b> and you want to apply <b>multiple poses at once</b> (or an entire <b>group</b>) with predictable pairing — for example a male pose on the male character and a female pose on the female character.=场景中有<b>多个角色</b>，需要<b>一次应用多个姿势</b>或整个<b>分组</b>时使用，可按预期配对，如男性姿势分配给男性角色、女性姿势分配给女性角色。
<b>When the button appears</b>=<b>按钮何时出现</b>
<b>Apply to characters…</b> shows on the character row or group bar when:=以下情况会在角色行或组操作栏显示<b>应用到角色…</b>：
• <b>Two or more</b> library poses are selected (checkboxes), or=• 用复选框选择了<b>至少两个</b>资料库姿势，或
• Exactly <b>one group entity</b> is selected (group header) — all members in <b>display order</b> are used.=• 恰好选择<b>一个分组实体</b>，使用其全部成员的<b>显示顺序</b>。
Not available during ZIP import preview. Requires at least one character selected in Studio.=ZIP 导入预览期间不可用，Studio 至少需选中一个角色。
<b>Setup — Chars window</b>=<b>设置角色窗口</b>
1. Open <b>Chars</b> (docked pane, like Tags / Sort).=1. 打开<b>角色</b>，与标签／排序一样使用停靠面板。
2. <b>Load characters from scene</b> appends new characters (gender from scene). <b>Remove missing from scene</b> deletes orange (not found) slots.=2. <b>从场景加载角色</b>添加新角色并读取场景性别；<b>移除场景中缺失项</b>删除橙色未找到槽位。
3. Reorder with <b>↑</b> / <b>↓</b> — <b>top \= highest priority</b>.=3. 使用 <b>↑</b>／<b>↓</b> 排序，<b>顶部优先级最高</b>。
4. <b>m</b> / <b>f</b> toggles gender for that slot; <b>✕</b> removes it. <color\=#ffbb88>Orange</color> \= not in scene; <color\=#88ffaa>green</color> \= selected in Studio.=4. <b>m</b>／<b>f</b> 切换槽位性别，<b>✕</b>移除。<color\=#ffbb88>橙色</color>表示不在场景中；<color\=#88ffaa>绿色</color>表示在 Studio 中已选中。
5. The list is saved to <b>pose_browser_character_config.json</b> in the Sandbox config folder.=5. 列表保存在 Sandbox 配置目录的 <b>pose_browser_character_config.json</b>。
<b>Studio selection</b>=<b>Studio 选择</b>
Select the characters you want to pose in Studio (workspace / gizmo). The character row shows count and names. Only <b>characters</b> count — props and accessories are ignored. Multi-apply uses <b>intersection</b> of Studio selection and your priority lists (plus unlisted selected characters at the end for untagged poses).=在 Studio 工作区／控制柄中选择要摆姿的角色，角色行会显示数量和名称。只统计<b>角色</b>，忽略道具和饰品。多角色应用使用 Studio 选择与优先级列表的<b>交集</b>；未列出的选中角色会追加到末尾，供无性别标签姿势使用。
<b>How poses are assigned</b>=<b>姿势分配方式</b>
Processing follows the <b>pose list order</b> (grid display order for groups). Each character receives <b>at most one pose per apply</b> — later poses never overwrite an earlier assignment on the same character.=按<b>姿势列表顺序</b>处理，分组使用网格显示顺序。每次应用中每个角色<b>最多获得一个姿势</b>，后续姿势不会覆盖之前分配。
<b>Male / Female pose tags</b> (case-insensitive, on the pose only)=<b>Male／Female 姿势标签</b>（不区分大小写，仅姿势标签）
• Pose tagged <b>Male</b> (not Female) → next available selected character marked <b>m</b> in the priority list.=• 标记为 <b>Male</b> 而非 Female 的姿势，分配给优先级列表中下一个空闲且已选中的 <b>m</b> 角色。
• Pose tagged <b>Female</b> → next available selected character marked <b>f</b> in list order.=• 标记为 <b>Female</b> 的姿势，按列表顺序分配给下一个空闲的 <b>f</b> 角色。
• Characters not in the list (or wrong gender for a tagged pose) are skipped for that pose.=• 未列出或性别不符的角色会被跳过。
• If both Male and Female tags are present, or neither tag is present, the pose is treated as <b>untagged</b> (see below).=• 同时带 Male 和 Female，或两者都没有时，视为<b>无性别标签</b>，见下文。
<b>Untagged poses</b>=<b>无性别标签姿势</b>
• Build priority order: top-to-bottom in <b>Chars</b>, then any selected characters not in the list.=• 优先级先按<b>角色</b>列表从上到下，再追加未列出的选中角色。
• First pass: pose 1 → first free slot, pose 2 → second free slot, etc. Extra poses with no free character are <b>skipped</b>.=• 第一轮：姿势 1 分给第一个空闲槽，姿势 2 分给第二个，以此类推。没有空闲角色的额外姿势会<b>跳过</b>。
• Second pass: any selected character still without a pose gets a pose by cycling through the pose list (only if eligible for that pose’s gender tag).=• 第二轮：尚未获得姿势的选中角色按姿势列表循环分配，但仍须符合姿势性别标签。
<b>Example workflows</b>=<b>流程示例</b>
<b>Couple (M + F tags)</b> — Group with two poses tagged Male and Female. Select both characters in Studio. Select the group header → <b>Apply to characters…</b>. Optionally save positions after arranging spacing, then re-apply the group later with layout restored.=<b>双人（M + F 标签）</b>：分组中两个姿势分别标记 Male、Female。选中两个角色，再选组标题 → <b>应用到角色…</b>。布置间距后可保存位置，日后重用时恢复布局。
<b>Five generic poses, three characters</b> — Untagged poses; only the top three priority characters are posed; poses 4–5 skipped.=<b>五个通用姿势、三个角色</b>：无性别标签，仅前三个优先级角色获得姿势，姿势 4–5 跳过。
<b>Two poses, four characters</b> — After the first pass, two characters remain; second pass applies poses 1 and 2 again to them (different characters, not overwrites).=<b>两个姿势、四个角色</b>：第一轮后剩两个角色，第二轮为它们再次应用姿势 1、2，不覆盖先前角色。
<b>Single-pose apply</b> (left-click thumbnail) still applies one pose to <b>all</b> selected Studio characters at once — separate from multi-character mapping.=<b>单姿势应用</b>（左键缩略图）仍向选中的<b>所有</b>角色应用同一个姿势，与多角色映射不同。
<size\=17><b>Import & export (ZIP v2 / v3)</b></size>=<size\=17><b>导入与导出（ZIP v2 / v3）</b></size>
Pose Browser exchanges packs as <b>.zip</b> archives with <b>manifest.json</b>, <b>metadata.json</b>, and pose binaries under <b>poses/</b>. <b>v3</b> adds optional <b>groups[]</b> in metadata (names, group tags, member paths). The reader only accepts <b>stored</b> (uncompressed) ZIP entries—recompressing with Deflate breaks import.=姿势浏览器使用含 <b>manifest.json</b>、<b>metadata.json</b> 和 <b>poses/</b> 下姿势数据的 <b>.zip</b> 包。<b>v3</b> 在元数据中加入可选 <b>groups[]</b>，包含名称、组标签和成员路径。读取器仅接受<b>stored</b>（不压缩）条目，改用 Deflate 重压缩会导致导入失败。
<b>Import…</b>=<b>导入…</b>
1. Choose a pack file. A <b>preview grid</b> replaces the normal listing.=1. 选择包文件，<b>预览网格</b>会替代普通列表。
2. Check poses to import (thumbnail toggles; or checkbox with Ctrl/Shift range). <b>Cancel import</b> in the bottom bar abandons the operation.=2. 勾选要导入的姿势，可点缩略图或使用复选框与 Ctrl/Shift。底部<b>取消导入</b>会放弃操作。
3. Pick a destination: click <b>Root only</b> or a folder name in <b>Folders</b> so the footer shows <b>Apply</b>/<b>Cancel</b> for the import.=3. 在<b>文件夹</b>中点击<b>仅根目录</b>或文件夹名，底部会显示导入<b>应用</b>／<b>取消</b>。
4. <b>Apply</b> writes files. <b>Tree branch</b> packs create one new subfolder (named in the manifest) under the folder you picked.=4. <b>应用</b>写入文件；<b>目录分支</b>包会在所选目标下创建一个按清单命名的新子目录。
<b>Export…</b> (selection bar)=<b>导出…</b>（选择栏）
Select poses that already live in your library, then export a flat v5 ZIP with tags/favorites and pose groups (when fully selected; offsets and body heights when saved) in metadata.=选择资料库已有姿势，导出带标签／收藏和完整选中分组元数据的平面 v5 ZIP；保存过的偏移与身高也会包含。
<b>Export branch…</b> / <b>Export library tree…</b>=<b>导出分支…</b>／<b>导出整个资料库目录树…</b>
In <b>Full</b> layout, the folder footer offers <b>Export branch…</b> when a folder is selected, and <b>Export library tree…</b> at library root—hierarchical branch packs for sharing whole subtrees.=<b>完整</b>布局下，选择文件夹后底部提供<b>导出分支…</b>，资料库根目录提供<b>导出整个资料库目录树…</b>，可按层级分享整个子树。
Modders: full field reference and JSON examples — <b>Modules/PoseBrowser/POSE_ZIP_FORMAT.md</b> in the HS2-Sandbox repository.=开发者可在 HS2-Sandbox 仓库的 <b>Modules/PoseBrowser/POSE_ZIP_FORMAT.md</b> 查看完整字段说明和 JSON 示例。

<b>Requirements</b>=<b>要求</b>
• <b>Exactly as many characters selected in Studio as poses</b> in the group.=• <b>Studio 选中角色数必须等于姿势数</b>。
• One-to-one assignment must succeed: <b>Male</b> / <b>Female</b> pose tags and the <b>Chars</b> priority list (see <b>Multi-character apply</b>).=• <b>Male</b>／<b>Female</b> 姿势标签与<b>角色</b>优先级列表必须能一一匹配，参见<b>多角色应用</b>。
• Poses do <b>not</b> need to be applied beforehand — the capture run applies them.=• <b>不需要</b>预先应用姿势，捕获流程会自动应用。
• Disabled during ZIP import preview or while another capture overlay is active.=• ZIP 导入预览或其他捕获浮层启用时不可用。
<b>Workflow</b>=<b>流程</b>
1. Select characters in Studio; select the group header.=1. 在 Studio 选择角色，并选中分组标题。
2. Click <b>Group thumbnails…</b>. All poses are applied at once using the same rules as <b>Apply to characters…</b> (including <b>Apply relative positions</b>, <b>Adjust for body height</b>, and <b>Adjust for object scale</b> when those toggles are on).=2. 点击<b>分组缩略图…</b>，按<b>应用到角色…</b>相同规则一次应用所有姿势，包括启用的<b>应用相对位置</b>、<b>按身高调整</b>、<b>按物件缩放调整</b>。
3. Frame the scene in the overlay.=3. 在浮层中调整场景取景。
4. For each pose in <b>display order</b>, characters assigned to other poses render in Studio <b>simple color</b> (monocolor) so only the focus character shows full detail.=4. 按<b>显示顺序</b>处理姿势，其他角色使用 Studio <b>单色显示</b>，仅焦点角色显示完整细节。
5. Use <b>Capture</b>, <b>Skip</b>, <b>Auto-capture</b>, or <b>Cancel</b> as in single-pose capture. Status shows <b>Group thumb n / total</b>.=5. 与单姿势捕获一样使用<b>捕获</b>、<b>跳过</b>、<b>自动捕获</b>或<b>取消</b>。状态显示<b>分组缩略图 n / 总数</b>。
<b>Example:</b> Group with poses 1 and 2; characters A and B assigned by priority. Pose 1 captures with B in monocolor; pose 2 captures with A in monocolor.=<b>示例：</b>姿势 1、2 分配给 A、B。捕获姿势 1 时 B 单色显示；捕获姿势 2 时 A 单色显示。
Missing thumbnails use a neutral placeholder until a file is loaded or regenerated.=缺失缩略图会使用中性占位图，直到图片被加载或重新生成。

<b>Pose Browser — quick manual</b>=<b>姿势浏览器 — 快速手册</b>
Library: <b>UserData/studio/pose</b>. Open from the Sandbox toolbar (pose icon). Resize the main window from the bottom-right grip.=资料库：<b>UserData/studio/pose</b>。从 Sandbox 工具栏的姿势图标打开，拖动右下角调整主窗口大小。
<b>Top bar</b>=<b>顶部栏</b>
• <b>Chars</b> — multi-character priority list. Character label shows Studio selection.\n• <b>Update v…</b> — appears when a newer Pose Browser release is available.\n• <b>Save Pose</b> — save current character pose into the active folder (selected folder, pose root in <b>All poses</b> or <b>Favorites</b> view).\n• <b>Import…</b> — open a pose pack <b>.zip</b> (manifest v2–v4; preview in the grid, then pick a destination folder and <b>Apply</b> in the folder footer).\n• <b>Undo</b> / <b>Redo</b> / <b>History</b> — pose history for Studio-selected characters.\n• <b>Stash</b> — quick pose clipboard (see <b>Pose stash</b> below). In compact views, <b>Stash</b> is on the character row.=• <b>角色</b>：多角色优先级列表，角色标签显示 Studio 选择。\n• <b>更新至 v…</b>：发现新版姿势浏览器时显示。\n• <b>保存姿势</b>：将当前角色姿势写入当前文件夹；在<b>全部姿势</b>或<b>收藏</b>视图中则写入根目录。\n• <b>导入…</b>：打开姿势包 <b>.zip</b>（清单 v2–v4），先预览网格，再选目标文件夹并在底部<b>应用</b>。\n• <b>撤销</b>／<b>重做</b>／<b>历史</b>：操作 Studio 选中角色的姿势历史。\n• <b>暂存</b>：快速姿势剪贴板，参见下方<b>姿势暂存</b>。紧凑视图中，<b>暂存</b>位于角色行。
<b>Grid — search & selection</b>=<b>网格 — 搜索与选择</b>

<b>Pose groups (grid)</b>=<b>姿势分组（网格）</b>
• Select <b>2+ ungrouped</b> poses → bottom bar <b>Group…</b> (name the group). <b>Ungroup</b> removes membership.\n• <b>Group header</b> (▦ row) \= select the <b>group entity</b> (rename, tags, export, <b>Apply to characters…</b>, <b>Group thumbnails…</b>, save/clear <b>positions</b>). Card checkboxes \= individual poses.\n• <b>Exclude</b> tag filters: hide ungrouped poses; grouped poses use <b>group + pose</b> tags. In a visible group, excluded tags dim cards (red tag text).\n• <b>Grouped poses</b> / <b>Thumbnails</b> in the tag filter panel cycle neutral → hide (−) → only (+), like per-tag filters.\n• Move/Copy one <b>full group</b> at a time. Data: <b>pose_groups.tsv</b> in Sandbox config.=• 选择<b>至少两个独立</b>姿势 → 底部<b>分组…</b>并命名。<b>取消分组</b>移除成员关系。\n• <b>分组标题</b>（▦ 行）选择<b>分组实体</b>，用于重命名、标签、导出、<b>应用到角色…</b>、<b>分组缩略图…</b>及保存／清除<b>位置</b>；卡片复选框选择单个姿势。\n• <b>排除</b>标签会隐藏独立姿势；组内使用<b>分组 + 姿势</b>标签，排除成员变暗且标签为红色。\n• 标签筛选中的<b>分组姿势</b>／<b>缩略图</b>按中立 → 隐藏（−）→ 仅显示（+）循环。\n• 每次移动／复制一个<b>完整分组</b>。数据保存在 Sandbox 配置中的 <b>pose_groups.tsv</b>。
<b>Group relative positions</b>=<b>分组相对位置</b>
Save character spacing and facing for a group and re-apply it with the group. The <b>first pose</b> in grid display order is the <b>anchor</b> (position and rotation reference). Every other pose stores a <b>local position offset</b> (in the anchor's frame), <b>relative rotation</b> (vs anchor), <b>maker body height</b>, and <b>Studio object scale</b> on that pose path. Persisted in <b>pose_groups.tsv</b> and v7 ZIP (<b>memberRelativeOffsets</b>, <b>memberRelativeRotations</b>, <b>memberBodyHeights</b>, <b>memberObjectScales</b>).\n\n<b>To save positions</b> (<b>Save positions…</b> on the group bar):\n1. Set up <b>Chars</b> and pose <b>Male</b> / <b>Female</b> tags if needed.\n2. Select <b>exactly as many characters as poses</b> in Studio.\n3. Apply the group (<b>Apply to characters…</b>) so poses map in <b>display order</b> (first pose → anchor character).\n4. Arrange characters, then <b>Save positions…</b> without applying another pose in between (see button tooltip if disabled).\n\n<b>To apply saved positions</b> — same apply path (same pose order and <b>Chars</b> priority). After poses are applied:\n• <b>Apply relative positions</b> (global; group bar or <b>Options</b>) — each non-anchor character moves to <b>anchor position + anchor rotation × saved offset</b> (orbits with the anchor) and rotates to <b>anchor rotation × saved relative rotation</b>. The anchor character is not moved.\n• <b>Adjust for body height</b> (needs relative positions on) — still applies the full offset, but <b>offset.y</b> is scaled from saved vs current body-height ratios on each pose path (spread ratio when heights differed at save; otherwise anchor or averaged scale). No fixed meter constant.\n• <b>Adjust for object scale</b> (needs relative positions on) — scales saved offset <b>X/Y/Z</b> from saved vs current Studio object-scale ratios (same spread logic as body height). Relative rotation is unchanged.\n• <b>Clear positions</b> — removes stored offsets, heights, scales, and rotations for that group.=保存分组角色间距和朝向，应用分组时恢复。显示顺序中的<b>第一个姿势</b>是<b>锚点</b>，作为位置和旋转基准。其余姿势按路径保存<b>局部位置偏移</b>、<b>相对旋转</b>、<b>角色编辑器身高</b>与<b>Studio 物件缩放</b>。数据写入 <b>pose_groups.tsv</b> 和 v7 ZIP 的 <b>memberRelativeOffsets</b>、<b>memberRelativeRotations</b>、<b>memberBodyHeights</b>、<b>memberObjectScales</b>。\n\n<b>保存位置</b>（分组栏的<b>保存位置…</b>）：\n1. 按需设置<b>角色</b>和姿势的 <b>Male</b>／<b>Female</b> 标签。\n2. 在 Studio 选择<b>与姿势数恰好相同的角色</b>。\n3. 用<b>应用到角色…</b>应用分组，按<b>显示顺序</b>映射，第一个姿势对应锚点角色。\n4. 布置角色后点击<b>保存位置…</b>，期间不要应用其他姿势；按钮不可用时查看提示。\n\n<b>应用已保存位置</b>使用相同姿势顺序和<b>角色</b>优先级。应用姿势后：\n• <b>应用相对位置</b>为全局开关，位于分组栏或<b>选项</b>。非锚点角色移到<b>锚点位置 + 锚点旋转 × 保存偏移</b>，旋转为<b>锚点旋转 × 保存相对旋转</b>；锚点不移动。\n• <b>按身高调整</b>需要相对位置开启，保留完整偏移，但按保存和当前身高比例缩放 <b>offset.y</b>；保存时身高不同则按差距比例，否则用锚点或平均缩放，不用固定米数。\n• <b>按物件缩放调整</b>同样需要相对位置，按保存和当前 Studio 缩放比例调整 <b>X/Y/Z</b>，逻辑与身高相同，相对旋转不变。\n• <b>清除位置</b>移除该组保存的偏移、身高、缩放和旋转。
<b>Thumbnails</b>=<b>缩略图</b>
<b>Thumbnails…</b> (selection bar, one or more poses checked) — capture preview PNGs for selected library poses. Each step applies that pose to Studio-selected character(s), then opens the capture overlay: drag/resize the green frame, <b>Capture</b>, <b>Skip</b>, <b>Auto-capture</b> (remaining poses after a configurable pause — Options / BepInEx), or <b>Cancel</b>.\n\n<b>Group thumbnails…</b> (group entity bar when the <b>group header</b> is selected) — capture one thumbnail per pose in the group while all characters stay posed together:\n• Requires <b>exactly as many Studio characters as poses</b>, with the same one-to-one gender / <b>Chars</b> assignment as multi-character apply (poses need not be applied beforehand).\n• On start: applies <b>all</b> group poses at once (same path as <b>Apply to characters…</b>, including <b>Apply relative positions</b> / height / object-scale toggles when enabled).\n• Overlay: frame the whole scene once. For each pose in display order, characters assigned to <b>other</b> poses render in Studio <b>simple color</b> (monocolor) so only the focus character shows full detail.\n• <b>Capture</b> saves that pose's PNG and advances; <b>Skip</b> leaves that pose unchanged; <b>Auto-capture</b> chains the rest; <b>Cancel</b> restores all characters from monocolor. Not available during import preview.=<b>缩略图…</b>位于选择栏，需勾选至少一个姿势，用于捕获资料库姿势的 PNG 预览。每步先将姿势应用到 Studio 选中角色，再打开浮层：可拖动／缩放绿色框，选择<b>捕获</b>、<b>跳过</b>、<b>自动捕获</b>（按选项／BepInEx 中的等待时间处理剩余姿势）或<b>取消</b>。\n\n选择<b>分组标题</b>后，分组操作栏的<b>分组缩略图…</b>可让所有角色保持共同摆姿，为每个姿势捕获一张图：\n• <b>Studio 角色数必须与姿势数相同</b>，按多角色应用相同的性别／<b>角色</b>规则一一匹配，不必事先应用姿势。\n• 开始时按<b>应用到角色…</b>相同路径一次应用<b>全部</b>姿势，包含启用的<b>应用相对位置</b>、身高与物件缩放。\n• 只需设置一次整体取景。按显示顺序处理时，分配到<b>其他</b>姿势的角色使用 Studio <b>单色显示</b>，仅焦点角色显示完整细节。\n• <b>捕获</b>保存当前 PNG 并前进；<b>跳过</b>不改当前项；<b>自动捕获</b>连续处理剩余项；<b>取消</b>恢复所有角色正常显示。导入预览期间不可用。
<b>Multi-apply</b>=<b>多角色应用</b>
• <b>Chars</b> (top bar) opens the <b>priority list</b> (top \= first). <b>Load characters from scene</b>, <b>Remove missing from scene</b>, ↑↓ reorder, <b>m</b>/<b>f</b> gender button, ✕ remove. Saved in <b>pose_browser_character_config.json</b>.\n• <b>Apply to characters…</b> when <b>2+ poses</b> selected, or <b>one group header</b> selected. Select characters in Studio first.\n• <b>Male</b> / <b>Female</b> <i>pose</i> tags → next free character of that gender in list order. <b>Untagged</b> → list order top to bottom; each character gets at most <b>one</b> pose per apply (extras skipped; leftover chars may get a second-pass pose).\n• Left-click thumbnail still applies <b>one</b> pose to <b>all</b> selected characters (separate from multi-apply).=• 顶部<b>角色</b>打开<b>优先级列表</b>，顶部优先。<b>从场景加载角色</b>、<b>移除场景中缺失项</b>、↑↓ 排序、<b>m</b>/<b>f</b> 性别按钮、✕ 移除。数据保存在 <b>pose_browser_character_config.json</b>。\n• 选择<b>至少两个姿势</b>或<b>一个分组标题</b>后可<b>应用到角色…</b>，需先在 Studio 选中角色。\n• <b>Male</b>／<b>Female</b> 的<i>姿势</i>标签按列表顺序分给同一性别的空闲角色。<b>无标签</b>按列表顺序分配；每次每个角色最多获得<b>一个</b>姿势，额外姿势跳过，剩余角色可在第二轮分配。\n• 左键缩略图仍将<b>一个</b>姿势应用到<b>全部</b>选中角色，与多角色分配不同。
<b>Pose history</b>=<b>姿势历史</b>
• Each pose apply records <b>before</b> and <b>after</b> snapshots (absolute pose, position, rotation) per character. The pre-apply entry is skipped when unchanged from the current history point.\n• <b>Undo</b> / <b>Redo</b> (top bar or shortcuts) affect only <b>Studio-selected</b> characters. <b>History</b> pane lists the same selection, grouped by character, newest first.\n• Click a history line to jump to that snapshot; checkboxes choose pose / position / rotation. Data: <b>pose_browser_history.json</b>. Max entries per character: <b>Options</b> and BepInEx config.=• 每次应用按角色记录<b>之前</b>和<b>之后</b>的绝对姿势、位置、旋转快照；应用前状态与当前历史点相同时跳过重复记录。\n• 顶部或快捷键的<b>撤销</b>／<b>重做</b>只作用于<b>Studio 选中</b>角色。<b>历史</b>面板也按这些角色分组，最新记录在前。\n• 点击历史项跳转到快照，复选框控制姿势／位置／旋转。数据：<b>pose_browser_history.json</b>。每角色上限在<b>选项</b>与 BepInEx 配置中设置。
<b>Pose stash</b>=<b>姿势暂存</b>
A temporary pose clipboard (FK/IK only — not saved to the library). Distinct from <b>History</b> (automatic undo timeline).\n\n<b>Stash</b> (top bar, or character row in <b>List</b> / <b>Mini</b>) — toggles the stash panel open or closed. If already open (docked or floating), it closes. If closed, it reopens in the last mode you used (<b>docked</b> beside the browser or <b>floating</b>).\n\n<b>Stash selected character</b> — capture from <b>exactly one</b> Studio-selected character. Each entry is labeled with character name and timestamp.\n<b>Click an entry</b> — apply that stashed pose to <b>all</b> currently selected characters (one or many).\n<b>x</b> on a row — delete that entry (<b>Yes</b> / <b>No</b> confirm). <b>Clear entire stash</b> at the bottom (confirm required).\n<b>Auto-delete after apply</b> — remove an entry once applied.\n\n<b>Docked pane</b> — side panel like <b>History</b>; closes when the main Pose Browser closes. <b>Float</b> undocks to a free window (drag title bar, resize ◢).\n<b>Floating window</b> — <b>Dock</b> re-attaches beside the browser (or closes if the browser is hidden); <b>×</b> closes only the stash. Stays open when you close the main browser.\n\nHotkey <b>Toggle undocked pose stash</b> — open/close the <b>floating</b> stash only (Configuration Manager → <b>Pose Browser · Keyboard shortcuts</b>).\nData: <b>pose_stash.json</b>. Floating window size/position and dock vs float preference: <b>pose_browser_options.json</b>.=临时姿势剪贴板，只存 FK（正向运动学）／IK（逆向运动学），不写入资料库；与自动撤销时间线<b>历史</b>不同。\n\n<b>暂存</b>位于顶部或<b>列表</b>／<b>迷你</b>视图的角色行，点击切换开关。关闭后按上次模式重新打开，可为浏览器旁的<b>停靠</b>或独立<b>浮动</b>。\n\n<b>暂存选中角色</b>需在 Studio 中<b>恰好选择一个</b>角色，每项标注角色名称和时间。\n<b>点击条目</b>将姿势应用到当前选中的<b>所有</b>角色。\n行上的 <b>x</b> 删除该项，需<b>是</b>／<b>否</b>确认；底部<b>清空全部暂存</b>也需确认。\n<b>应用后自动删除</b>会在应用后移除条目。\n\n<b>停靠面板</b>像<b>历史</b>一样随主窗口关闭。<b>浮动</b>可将其变成独立窗口，拖动标题栏和 ◢ 调整。\n<b>浮动窗口</b>中的<b>停靠</b>将其挂回浏览器旁，浏览器隐藏时则关闭；<b>×</b>只关闭暂存，主浏览器关闭时可保持打开。\n\n快捷键<b>切换浮动姿势暂存窗口</b>只控制<b>浮动</b>暂存，位于配置管理器 → <b>姿势浏览器 · 快捷键</b>。\n数据：<b>pose_stash.json</b>。浮窗大小／位置及停靠偏好：<b>pose_browser_options.json</b>。
<b>Compact views</b>=<b>紧凑视图</b>
<b>View (…)</b> in the top bar (Window section) cycles <b>Full → List → Mini → Full</b>; choice is saved.
