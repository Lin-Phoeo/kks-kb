# 使用与排查教程

## 选择安装方式

已有受检的 KKS 中文整合环境，可先运行基础包 doctor，再按需本地导入现成词。不同插件版本同时存在时，先以本机实际 DLL 和启动日志核对版本。可选辅助功能跳过的原因会出现在预检 JSON 中。

独立窗口由 XUnity 精确词和规则翻译。F1 设置按插件 GUID、分组、配置键及原文匹配。原生对话框和图片文字走各自的修订路径。它们共享中文术语，但加载方式不同。

## F1 窗口

按 F1，搜索插件的原始名称，例如 bettersceneloader。搜索、保存和配置值沿用原插件身份。显示适配器在绘制期间临时提供中文名称和说明，随后恢复原始元数据。

如果标题已中文、内部控件仍英文，先看 XUnity Core 和 IMGUI 路由适配器是否按兼容清单加载。本项目修复两个独立问题，Unity 的 GUILayout.Window 会包装原回调，旧 Core 的泛型缓存选择又会混用多个插件。HiDPI 会进一步包装回调，因此只更新 Core 仍可能不足。

说明悬停需要真实打开 F1 后检查。普通标签缓存命中不能证明 GUI.tooltip 的最终显示。模板匹配会归一化原文的 CRLF/CR/LF，保留配置键和实际值。

## 布局和字体

原生侧栏按标题、正文、紧凑标签分别设定字号，基准最低 13 px，微调时的安全下限为 12 px。新用户默认保留原中文字体，可在 F1 的 Studio Font 中从中文字体列表主动选择等线、楷体等字体；“恢复默认中文与字号”会撤回字体、加粗和字号覆盖。旧 uGUI/IMGUI 与 TMP 使用不同字体对象，应记录各自有效家族和原生度量。不能仅凭一个字体文件加载成功判断全部文字系统正常。

看到方框时，记录出问题的字符与对应面板，查看 TMP 是否有中文主字体及原字体回退。看到小字时，检查是否为旧图标内像素字，或控件 BestFit 因宽度过窄缩小了文字。图标文字和实时文本需要分别修复。

F1 搜索 `Studio Font` 后，保留“统一界面字体”关闭即可沿用默认中文。需要更清楚的笔画时先试“文字加粗”；需要略大一些时将“字号微调”设为 1。反复调节不会在上一轮字号上继续叠加。点击“恢复默认中文与字号”会同时撤回字体家族、额外加粗及字号微调。

需要换字体时展开“选择中文字体”，搜索并点击中文名称，悬停可看原家族名。列表只列当前安装及运行环境能够可靠选择的中文候选；它不会卸载系统中的其他字体。首次筛选期间显示准备状态，失败时保留现有字体；筛选通过只表示覆盖检查中的常用汉字，不表示字体包含全部罕用字。

新版面板中可以搜索“微软雅黑”或 `YaHei`，两者会找到同一字体；悬停查看完整家族名。字号点击减小／增大，归零只恢复字号；顶端“恢复默认中文与字号”同时撤回本工具的字体、额外加粗和字号覆盖。手工路径收在高级设置中，输入不会立即加载；点击应用失败时，实际字体和设置会回到上次成功状态，错误提示保留以便改正路径。

## 常见结果

| 现象 | 先核对的证据 | 下一步 |
| --- | --- | --- |
| doctor 报未知 Core | DLL 哈希与 release-components.json | 使用受检官方版本或先完成版本适配 |
| 同名目标不同内容 | 预检给出的目标路径 | 保留文件，按旧回执回滚或审阅差异 |
| F1 内部仍英文 | Core、路由适配器、配置适配器加载日志 | 检查所有对应组件的版本 |
| 缓存全过但主窗口白 | Unity 主窗口可见状态和当前日志时间 | 从原启动器以 Normal 模式重启对照 |
| TMP 字体构造失败 | 有效字体家族、fallback、活动缺字数 | 使用受检中文 SDF 或完成字体控制器验收 |
| 退出仍有 Invalid handle | 堆栈是否指 ConsoleLogListener | 按旧控制台问题单独留档，不据此否定已写出的 JSON |

## 原生文件对话框

安装命令加 --native-ui，可在临时目录生成两个受检插件的对话框候选，核对原件与修订后哈希后，一起纳入同一安装回执。

~~~powershell
py studio_zh.py doctor --game "E:/Games/Koikatsu Sunshine" --native-ui --offline
py studio_zh.py install --game "E:/Games/Koikatsu Sunshine" --native-ui --offline --apply
~~~

未知插件版本会明确跳过。已经具有本包相同修订的文件保持原状。默认预检只在临时目录生成候选，只有 install --apply 才会备份并安装，回滚使用同一个 receipt.json。

## 记录可复现问题

保留插件名称和版本、面板入口、原文、预期中文、操作顺序、当前日志时间，以及是否已重启。分享截图前移除角色名、私人路径等不相关内容。若是动态文本，保留参数类型和格式，测试原名中有数字、括号、美元符号或反斜杠时是否完整。

基础包没有逐一打开所有可选插件窗口。与插件作者的原功能说明存在疑问时，应先查源码回调或正式文档，再调整术语。

字体切换后若某个窄面板文字被截短，先使用“恢复默认中文与字号”，再按该面板实际宽度校对。安装一个新字体时，先在 Windows 安装，再选择对应家族或文件。单机验证通过的切换和恢复不等于所有第三方字体都适配原游戏的控件宽度。
