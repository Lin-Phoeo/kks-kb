# 字体粗细与字号状态回归

仅使用合成控件和实际纯状态代码，不读取游戏安装或用户配置。

```powershell
dotnet run --project ops/studio-localization/tests/managed-typography -c Release
```

验证二十轮加粗／字号变化／恢复，包含当前值自赋值、外部插件改变基准、TMP 自动适配结果不污染基准、失败切换回滚、嵌套测量与绘制、异常恢复、复制临时样式时的原值、隐式零字号、固定输入高度契约和侧栏标题层级。

测量／绘制使用合成字体度量来验证调用期间的状态一致性，不证明 Unity 原生行高、Harmony 挂钩或最终像素排版。必须另在工作室确认 F1 空搜索框输入清空、字号 0→1→0、加粗、侧栏周期刷新和恢复默认中文。
