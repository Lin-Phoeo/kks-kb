# 变更与验证记录

## 0.3.0-rc.2 性能候选（尚未发布）

F1 目录与动态缓存采用值类型身份，减少重复拼串；未开启诊断时跳过 F1 观察收集。字体缓存整段短文本的字形覆盖，侧栏复用 Unity 原生 List 扫描缓冲区。Coordinate Load Option 对受检版本的默认语言资源键直接返回简中；未知键和显式语言请求保持原路径。默认宋体及切换方式不变。微基准不能当成游戏帧率证据，真实窗口验收状态见 VALIDATION.md。

## 0.3.0-rc.1 候选

整合已公开的 0.2.0-rc.3 基础修订，新增插件窗口、F1 精确上下文适配、侧栏文字布局、VideoExport 原生中文校正和便携安装工具。发行候选持续跟随当前验证构建，准确组件哈希见 release-components.json。

本轮重要对照按原结果保留。

| 阶段 | 发现 | 处理与验证范围 |
| --- | --- | --- |
| F1 词表 | 缓存 64/64，但 Confirm Delete 等仍英文 | 定位共享 Type 缓存和 Unity 窗口回调包装 |
| 官方 Core 加单指令修正 | 隔离探针通过，F1 正文仍英文 | 定位 HiDPI 额外包装，添加定向路由适配 |
| HiDPI 路由 | 三层回调已到达 SettingsWindow | 75/75 缓存、3/3 真实 GUIContent 与用户正常退出通过 |
| 全插件整包 | 1,308 精确缓存通过，TMP OS 字体失败 | uGUI 保持微软雅黑，TMP 使用已有 Arial Unicode SDF 并保留原字体回退 |
| F1 整包运行补查 | 运行时新增标签及 CRLF/LF 差异 | 补齐 24 个标签，17 条说明匹配差异闭合 |
| 字体控制器 | 系统字体可构造，F1 自定义控件类型名不符 | 改用 ConfigurationManagerAttributes，真实注册和快捷选择通过 |
| PerspectiveX | 高频 IMGUI 路径禁用普通 regex | 新增有界动态与长文桥接，7/7 真实绘制检查通过 |
| 字体度量第一轮 | 字体热切影响搜索框尺寸 | 1.0.2 的字号恢复和 CalcSizeWithConstraints 修订未通过实际搜索框验收，保留失败记录 |
| 字体度量第二轮 | 路径字体用于旧 uGUI/IMGUI 时 lineHeight 为 0 | 1.0.3 改用旧文字系统 OS Font、TMP 路径字体，9 次切换与用户搜索、恢复、退出通过 |
| F1 搜索布局 | AniMorph 自定义 Flags 绘制受配置列表切换影响 | 单独的受检版本兼容辅助，8 项托管回归，实际搜索与字体热切联合验收通过 |
| 默认字体 | 用户选择宋体并要求保留楷体快捷切换 | 1.0.4 调整默认启用宋体，保留用户已有配置，24 项策略/注册检查通过 |

主窗口曾出现白屏同时 Win32 标记隐藏，原词表与插件保持相同后，经 Normal 模式重启恢复。该对照包含进程重启，唯一成因未确定。退出的旧 ConsoleLogListener Invalid handle 仍按独立问题留档。
