# CM19.1 配套候选：安装前先读

本地候选版本为 **0.3.0-rc.3-cm19.1**。它尚未公开发布，本页不提供未发布的下载链接。旧 **0.3.0-rc.2** ZIP 与已有发行页面保持原样，仍是 ConfigurationManager19.0 的历史配套路径。

本候选的配置中文 helper1.0.2、AniMorph 布局 helper1.0.1 仅接受 ConfigurationManager19.1 的 SHA256：

`143bb25e8f03ed8728224de0b72752de29c0962ff69d20ec685831ec7491b323`

包内不含 ConfigurationManager，也不会替你升级它。先保存退出 Studio，在独立备份中保留原 manager 和两个 helper，再由正常可信来源准备准确管理器。不可通过改哈希或文件名绕过检查。管理器不匹配时，这两个可选 helper 会被预检跳过；这不是安装成功。

解压到游戏以外的新目录。先运行 `py studio_zh.py doctor --game "<游戏目录>" --offline`，检查 manager 及 helper 相关项，再决定是否 `install --apply`。不要把整个候选目录直接拖进游戏插件目录。其余词表、字体、HiDPI 与动态桥保留既有安装器的合并、版本和备份规则。

准确组合已在空 Studio 完成45项原生检查：五个临时搜索状态实际重绘，中英插件标题和中文设置显示、搜索框高度、XUnity owner、HiDPI回调路由以及窗口/光标/配置状态恢复均通过。没有模拟真人输入，也未验枚举下拉交互、tooltip像素、滚动展开、字体切换、AniMorph行宽、长滑条值或PerspectiveX窗口。完整范围见 [CM19.1记录](records/configuration-manager-19-1.md)。

要回到 CM19.0，须在 Studio 退出后成组恢复 manager 与这两个 helper。安装器只回滚它自己回执中管理的文件；另行升级的 ConfigurationManager 不在汉化包回滚范围内，须用自己的原件备份恢复。配置或文件在安装后又被修改时，保留变化并按回执核对，不能强制覆盖。
