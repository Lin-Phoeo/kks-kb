# 字体、粗细与字号的独立控制

默认保留已汉化界面的原字体，文字加粗关闭、字号微调为 0。字体替换开关只控制字体家族；加粗和微调在保留原字体时也可用。“恢复默认中文”同时关闭字体替换、取消额外加粗并将微调恢复为 0。

uGUI 和 TMP 保存各控件原 style、字号、自动适配开关及 min/max。重复应用以基准计算，不在已调整的字号上叠加；明确的外部 setter 更新基准，当前值自赋值保持幂等。TMP 内部自动拟合的结果不会作为新的用户基准，Italic、Underline 等样式位仍保留。切换失败的撤销同时恢复实际属性和跟踪状态。

IMGUI 字体、字号和粗细仅在测量／绘制／光标调用期间临时应用，由 finalizer 恢复。嵌套调用只应用一次；GUIStyle 从正在调整的样式复制时取回该作用域的原值，避免克隆继承增量。原字号 0 在调用中按原字体有效字号解析，返回后仍为 0。固定高度控件保留其高度和 padding，放大时按行高限制；不通过改输入框尺寸掩盖量度问题。

侧栏是其角色字号的唯一写入者。它读取 FontSelection 的 Bold／SizeDelta，并对标题、正文、紧凑标签的原角色尺寸应用同一 TypographyPolicy。控制器看到已注册的侧栏控件时跳过字号／粗细，避免周期扫描重复叠加。所有权首次交接前恢复受控制器拥有的字体和样式，再让侧栏保存基准，防止侧栏持有后来被释放的旧字体资源。未被 OnEnable 跟踪的非活动克隆也先登记；若克隆已带有本工具字体且无法追溯其原字体，使用当前会话的已知原字体基准，不保存该受管理字体为恢复目标。

字体列表由 resolver 在后台完成文件／中文字形检测后发布不可变快照，绘制仅消费缓存。旧原始字体标识保留，不由下拉约束静默改写；不能通过中文检测的旧值不出现在列表内。最终是否能应用，仍由实际系统字体身份、文件首字面及 Unity 原生量度共同检查。

纯合成回归位于 `tests/managed-typography/`。它验证实际状态类、作用域和侧栏策略，不替代 Unity 原生行高、Harmony 挂钩、搜索输入、真实侧栏和最终像素验收。运行摘要使用 `STUDIO_FONT_CATALOG_READY` 和每次设置应用后的 `STUDIO_FONT_TYPOGRAPHY_APPLIED`，不逐帧记录字体或文本。
