Shipped IL, rather than documentation alone, establishes the audited plugin's empty body.

It supplies no author repository in these entries. Global GitHub code searches for the exact GUID, `AutoKeyframe` plus `OnPostRender`, and matching issue text returned no relevant fix. Repository-name and public-web searches found unrelated programs or general mod lists. This is bounded search evidence, not a claim that no fix exists anywhere.

- The upstream release list was empty. The sole issue/PR was [#1, compilation configuration](https://github.com/countd360/CharaAnime/pull/1), unrelated to caps.
