# Sources and redistribution scope

- DragDoll author release thread: <https://discord.com/channels/447114928785063977/1568315694628479016>. The reviewed KKS 1.0.37 attachment belongs to message <https://discord.com/channels/447114928785063977/1568315694628479016/1573150196228034570>. Its package README calls enhanced Extra Move Axis a convenience recommendation, not a hard dependency. KKS and KK archive versions differ.
- Basic Extra Move Axis project: <https://github.com/ManlyMarco/StudioExtraMoveAxis>. An archived v3.1 package was separately compared; it is not the supported 2.0 binary and is not silently substituted by this tool.
- Harmony is already supplied by the user's game installation. No Harmony binary or upstream implementation is redistributed.
- Mono.Cecil: <https://github.com/jbevain/cecil>, MIT licensed; the caller supplies the existing library.

Only new identity helper, exact-input patch tool, extraction mapper, synthetic fixture and verification/documentation are present here. Original DLLs, decompiled classes, package contents, screenshots, private Discord messages, user data and local reports are excluded. The compatibility hashes intentionally identify exact supported binary inputs. Public accessibility of an attachment is not treated as permission to redistribute it.

The supplied original package permits scene/render creation while restricting some redistribution. This directory does not grant rights over that package or replace its license terms. No claim is made that an upstream general fix or all private author releases were exhaustively searched.
