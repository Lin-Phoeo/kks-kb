# DBDE 衣装切换生命周期修复

DynamicBoneDistributionEditor 的衣装切换方法按根骨骼名称寻找新的 DynamicBone。现装精确版本在候选骨骼、根骨骼或旧编辑主骨骼失效时直接取 `.name`，会中断切换；同方法在操作开始关闭 UI 更新，异常会跳过结尾的恢复。

这个定向工具只修这条路径：失效 Unity 对象不参与匹配，空编辑保留在原集合中并略过，销毁的衣装不再进入切换；UI 更新状态在 `finally` 中恢复为进入时的值。有效对象仍按原根名称精确比较、原 `List.Find` 顺序选择第一个，原来的绑定、应用和活动状态更新调用保持。异常不会被吞掉。若另一个 UI 实例在操作中取代原实例，只恢复捕获的旧实例。

此修复不实现“添加全部”、不改变动态骨骼归属规则、不新增编辑、不修改卡片、衣装或场景数据。其他方法中的独立失效对象问题不属于本补丁证明范围。

## 输入与变更范围

唯一支持原 DLL 的 SHA-256：`baa0fcc5c5658182385eb59694e34f5264fd68d87a2885b1ec91f15ee1d98f19`。

改动仅两个实际 CIL 方法：`DBDECharaController.ClothesChanged` 和其 `List.Find` 谓词。共 619 个方法中其余 617 个不变；不改程序集/GUID/版本、配置、资源、继承结构或其它插件。发行时使用哈希识别补丁，不能只靠 F1 的版本显示。

这里只包含自有工具及合成协作者，不发布第三方 DLL、完整反编译源码或游戏程序集。工具复用相邻 CameraFX 工具中的自有 CIL 复制器，运行时不依赖 CameraFX 插件。

## 可复现验证

需要 .NET 10 SDK、Python、用户现有精确原 DLL 与 KKS 的 Mono.Cecil/程序集引用。输出指定一个新的仓库外私有目录；入口拒绝游戏运行或内容目录。工具不安装候选、不启动游戏。

```powershell
py ops/community-plugin-repairs/dbde-clothes-lifecycle/run.py `
  --original /path/to/KKS_DynamicBoneDistributionEditor.dll `
  --game-root /path/to/KoikatsuSunshine `
  --output /path/to/new/private-dbde-verification
```

测试把原件或候选的实际 `ClothesChanged`、原编译闭包构造方法及谓词三段 CIL 提取到合成环境。Unity 对象失效状态、DBDE 属性 getter/绑定回调/刷新是明确的协作者；没有加载真实用户角色、调用真实物理引擎或读取场景。不是重写一份切换算法当作原件测试。

22 项涵盖正常同名绑定、不同名称、多个同名候选顺序、候选/旧主骨骼及各根的 null/销毁、空编辑后继续、加载早返、失效衣装、原 UI 已停用、UI 缺失/替换、刷新/应用抛错与恢复、其他坐标保持。原件 6 项通过/16 项失败；候选 22 项通过/0 失败。另有未知输入、已修输入、同一路径、已有输出、游戏目录、仓库目录、未知提取输入等拒绝检查。

## 安装与验收边界

本工具的绿灯不代表实际人物换装已通过。候选需先独立审查，再由主线与其他修复协调，等用户保存并正常退出 Studio 后备份准确旧 DLL，只替换同名候选。保留原配置及用户内容，检查同 GUID 只加载一次。

真实验收需要普通着装角色的换衣操作：有效动态骨编辑应保持原含义，遇到临时失效对象不应打断其它有效条目，面板应仍可更新。记录新的最小调用栈及候选哈希。回退时关闭 Studio，仅恢复准确备份 DLL；不能删除用户数据或将整个 DBDE 禁用当作修复。
