## Separate bounded native observation

On 2026-11-28, a separate empty-Studio run of the exact Free 1.7 local pair completed 89 checks with no failures. Dress-Up 1.11.9.1, Make-Up 1.0.3.1, PseudoMaker 1.5.2.0 and Modding API 1.48.1 identities matched the reviewed files. Each Vanity component naturally installed its display-refresh and coordinate-trim prefix once on the actual PseudoMaker methods; the observer did not call `EnsureInstalled` to manufacture that result.

The run also confirmed Make-Up's registration with the live Dress-Up bridge, window visibility transitions, and original Make-Up `OnEnter`/`OnExit` with no character session. Original navigation, shell fields, cursor/camera state and configuration hashes were preserved. Observer Awake, Start, run and cleanup each occurred once, with normal application-quit and destruction observed.

Vanity drawing was deliberately suppressed because the empty-selection Home flow can restore a reference card. Draw-dispatch counts are not visual verification. This observation did not read user cards, render the actual panels, exercise physical shortcuts, edit characters, test the author's color-channel fixes, or save/reload scene files. The prior Free 1.6 startup record remains a separate historical observation.
