# 验证范围

下列静态结果针对README列明的1.3.4与官方1.4.1精确DLL，不能推定同版本但不同字节的构建也符合。

| 检查 | 结果 | 边界 |
|---|---|---|
| 游戏/Unity/BepInEx直接成员引用 | 旧174/174，新212/212可解析 | 不证明动态VR反射和真实设备 |
| 旧配置section/key/type | 36项全部保留，新增20项，无删除 | 当前旧值保留由升级时私有前后比较确认；本工具不写插件cfg |
| 方法比较 | 同签名15项改变、85项不变；新增93、移除9，包含lambda更名 | 109→193方法数量不等于93个新功能 |
| 旧public API | 无删除；无参EnablePov保持 | 私有方法未知第三方反射不作全量保证 |
| 三预设及槽位/底部文字 | 39/39实际规则匹配 | 非像素、字号或真实绘制验收 |
| F1候选和动态候选 | 110项设置/说明查找及4项动态提示通过 | 使用现有TranslationCatalog/RuleMatcher，内存合并；没有全局替换 |
| 分发入口 | 12项临时合成测试通过 | 无真实游戏文件或进程读取 |

实际IL保持的方法包括`DrawPanel`、`OnGUI`、`DrawViewPresets`、`SaveViewSlot`、`LoadViewSlot`及预设序列化。相机启停、UpdateHotkeys和OnCameraPreCull有改变；因此不以文字规则通过替代POV操作验证。

新版仍声明`keelhauled.realpov`互斥。VR键鼠映射仅在活动VR路线使用；读源码可确认早退和节流，未用桌面结果推断VR性能。36项旧设置、saved/custom视角没有迁移到新格式；右键临时平移不写入原六字段槽位。

分发工具检查作者1.4.1准确哈希和rc.2辅助组件，借用现有事务执行两份JSON增量。脚本不升级DLL、不修改PerspectiveX配置或字体。传入不同DLL或存在冲突译文时拒绝；重复执行无新条目/回执，回滚恢复本次之前的文件，并拒绝覆盖后续修改。

## 真实空Studio观察

2026-11-28维护者在实际Studio中确认官方PerspectiveX1.4.1加载，工作区对象数为0，没有加载或保存人物卡/场景。安装时36项旧设置值保持，仅补两个缺失false；启动前38项（36旧项＋2新增默认）至启动后56项，原38项值全部保持，两项false仍为false。退出请求之前日志没有Error/Fatal。

`Application.Quit`请求后，仍需在核对自起进程PID与Unity窗口类后发送正常`WM_CLOSE`才完成退出，没有强制终止。退出阶段原有的控制台Invalid handle出现9次、JobTempAlloc警告33条，仍未修复，不能把本轮说成“退出完全无警告”，也没有证据将这些既有问题归因于PerspectiveX更新。临时观察器已核对哈希后移出插件目录。

该实测只证明插件初始化、配置保持及上述退出过程，不证明角色POV、预设实际点击、全部场景保存或头显体验。可公开的脱敏统计在[runtime-smoke-summary.json](runtime-smoke-summary.json)；不附机器路径、配置值、用户内容或原始日志。
