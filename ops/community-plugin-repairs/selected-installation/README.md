## 已完成的真实运行范围

**空场景 UI 检查：71 项通过、0 项失败。** 在实际 Studio 中核对精确组件身份并执行以下操作：SceneNotes 的真实 `SetNotes`、按钮颜色、窗口状态切换和已安装导入 helper；Radial 主/副菜单的实际 Canvas 构造及关闭；DragResize 自有 `RectTransform` 与隔离测试配置的保存/读取；StudioFixes 已创建模块/按钮；Lite 的被动加载状态。原状态恢复、自有对象销毁和最终空工作区检查通过，临时验收器已移出。

这个结果没有执行 SceneNotes 的真实场景保存/导入回调，也没有点击 Radial 动作、拖动用户面板、加载人物卡或验证 Lite 内容回放。窗口状态字段的同步切换不代表最终字体、排版或物理快捷键已经验收。未创建的 Quick Access 按钮保留未验证状态。

**自有媒体与 ReShade 链路检查：20 项通过、0 项失败。** 使用自造视频和物件检查 VideoPlate 的准备、RenderTexture、首帧暂停、播放、暂停、循环、停止及数据对象往返；使用自有摄像机和中性直通效果检查原生 KKReshade backbuffer 捕获、活动帧变化、关闭捕获后停止更新及控制恢复。最终工作区仍为空，原 ReShade 配置恢复，临时验收器已移出。

首次媒体尝试有未通过项：测试误将首帧暂停当作自动播放，且当时没有活动效果可供捕获回调观察。随后按 VideoPlate 实际操作调用播放，并使用自有直通效果重测，得到上述 20/20。初次失败没有计为通过，也没有通过更换业务插件掩盖失败。这不证明完整视频编码、全部 ReShade 效果、透明输出或用户场景保存已经可用。

参考进程在上述两次检查后退出。旧控制台 `Invalid handle` 退出信息仍存在，未被本记录宣布解决；插件检查与历史控制台故障分别保留。

## 参考安装与仍待验证的部分

四组候选已在参考环境安装并按候选 SHA 回读；各工具输出中的 `installed:false` 只表示**构建/验证工具自身没有安装**。ManageableSkirts 的人物裙骨交互、PovX 的真实输入、Timeline POV 切换及 StudioVoice 的播放/口型仍需各自的运行证据，不能由前述 71 项 UI 或 20 项媒体结果代替。

第三轮空场景端口观察的 **53 项限定检查通过、0 项失败**，包括 PerspectiveX/Timeline 反射与轨道读取、PovX 未活动时保留光标状态、StudioVoice 的 CSV/图标/轨道和限定 UI 观察，以及 Skirts 的空选择/helper 路径。**这一轮整体仍为部分通过**：启动日志另有旧 StudioVoice `e541…` 候选的 `MouthPatch` 未定义 Harmony 目标错误。观察器没有执行真实角色口型，因此其 53/53 不能覆盖这项错误。

随后 `bd61…` 候选将口型补丁绑定到真实 `CalcBlend(float openValue)` 前缀，保留原数值规则；独立重建、11 项实际 CIL 检查和 5 项拒绝保护通过，并已单独安装回读 SHA。第四轮实际 Studio 空场景检查 **57 项通过、0 项失败**；`Harmony.GetPatchInfo` 读回确认口型目标上存在准确 owner、`MouthPatch.Prefix` 和候选程序集，三个 PerspectiveX 挂钩也各匹配一次。启动检查未发现 Error/Fatal 或原来的未定义目标错误。这证明修订后的挂钩实际安装，仍不证明声音播放、人物口型画面或所有 Timeline 交互完成。

第四轮通过正常窗口关闭请求退出，进程已消失；准确哈希的临时验收器已移出插件目录。退出日志仍记录历史 `Invalid handle` 和 `JobTempAlloc` 信息，未在此轮修复，也不把它们藏入“全日志无错”的结论。第三轮失败历史保持。机器可读结果及剩余边界见 [verification-summary.json](verification-summary.json)。
