# 验证范围

入口是 [run.py](run.py)，参数必须显式提供作者原件、游戏依赖和新的外部输出目录。以下数字来自一次完整同机重建；没有安装或启动游戏。

## 行为对照

同一验证器调用原 DLL 与候选的实际方法：33 项中原件 8 项通过、25 项失败，候选 33 项全部通过。入口检查精确基线计数，不将无法加载程序集伪装成预期失败。

检查覆盖原隐藏节点和原颜色恢复，外部颜色/材质/发光/可见性修改，原列表身份/顺序/外部增删保留，实时新增裙骨，控制器与衣装替换，死亡对象，反复热键启停，配置关闭，缺相机/Studio，恢复失败可观测且可再次处理。

V2 额外覆盖半锥创建的 99 顶点和 2 子网格，锥体开关的清理/重建，原 Renderer 初始禁用状态，隐藏最后节点但完整列表保留，透明度设置，裙骨 active 状态恢复，以及移除锥体目标后的刷新。

独立审查在另一外部目录完整重建，候选和 helper 哈希一致，并额外验证控制器替换后再次启用、着色开关往返、活骨移除后重加入，以及外部重新开启 Renderer 后的更新/恢复，合计 37/37 通过。审查未发现阻断试装的确定问题。

这些结果验证托管状态流程；夹具没有真实 Unity native、GPU、Mono、碰撞器命中或用户操作输入。

## IL 与 ABI

- 原 51 个方法中 11 个目标方法变化，40 个标准化 IL、局部变量和异常处理结构保持。
- 候选与 helper 均无原生 BoneInfo 列表修改；helper 无 Transform setter 或 P/Invoke。候选原有锥体 Transform 更新保留。
- 36 个 helper 游戏/API 成员在实际目标安装元数据中解析成功；12 个新增 helper 调用的返回/参数类型和静态公开签名匹配。
- 反射访问的插件字段、关键方法签名及私有数据字段匹配指定 V2 原件。
- 原 AssemblyRef 保持，仅新增 `Codex.ManageableSkirtsV2State`；未添加第二个核心库引用。
- `GetConeMesh` 与 `UpdateConeGuideTransform` 保持原 IL；独立审查确认方向/轴向算法保留，实际画面与交互仍以 Unity 验收为准。
