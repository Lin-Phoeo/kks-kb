# 项目结构

```text
app/                 FastAPI 入口、模板、静态资源
  kb/content/        文档元数据、原件索引、阅读投影和图像映射
  kb/retrieval/      FTS、向量检索、融合与评估接口
  kb/web/            HTTP 路由与页面上下文
pipeline/kbpipe/     离线构建流水线
ops/tools/          通用资料处理工具
ops/deploy/         可测试的备份和检查工具，不是自动发布流程
eval/               检索评估代码及自建问题集
tests/              合成数据测试
scripts/            演示创建与开发检查入口
docs/               公开开发说明
```

运行时在仓库旁读取本地 `config.json` 和 `data/`。文档索引位于 `data/kb.db`，向量与 ID 映射为伴随文件；用户、会话等状态由独立状态库管理。配置、数据库和实际资料均被 Git 忽略。

原件通过精确文档键、文件长度和 SHA-256 关联；阅读版是衍生 HTML。语义阅读依赖的正文或原件哈希不匹配时回退已有阅读方式，保留检索引用与旧路由。

本仓库的演示数据和测试夹具完全自造。生产资料数量、部署路径、采集历史和原件分发范围不属于代码事实，应由各部署自行记录。
