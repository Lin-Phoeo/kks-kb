# 阅读页导航与验证

语义阅读页默认显示标题、作者/来源、适用状态和原件下载。完整出处列表、归档路径、原件SHA256与阅读说明放在“适用范围、出处与校验”中，展开后可核对；未知版本与未实测状态不会因为折叠而被隐藏。

目录和正文书签共用导航处理：兼容旧书签映射、URL片段和 `sec` 参数，打开目标所在的折叠内容，并根据固定顶栏和阅读工具栏实际高度避让。正文在字体加载、字号改变时可能分帧重排，导航在此期间保持落点；用户开始滚轮、触控、指针或键盘浏览后停止保持，避免干扰阅读。

窄屏目录默认折叠，选择章节后收起。没有原文标题的资料继续保留无目录状态，不自动编造章节。

验证入口是 `tests/test_reader_browser.py`，通过真实临时FastAPI响应和隔离Chromium检查：

- 三种视口的首屏正文、必要状态、来源和原件入口。
- 新旧片段、正文点击、`sec`、hashchange及异常百分号片段。
- 折叠内容祖先展开、前进后退和无关折叠区保持。
- 手机目录选择、大字号稳定落点及用户滚动解除自动对齐。

这是桌面浏览器模拟检查。iOS/Android实机触摸、系统阅读器和生产缓存交付仍需单独验收。
