# 数据与配置

`config.example.json` 描述配置结构，真实值放在未跟踪的 `config.json`。使用演示生成器时，它会创建专用演示配置与合成数据，已有配置或数据时拒绝覆盖。

LLM、嵌入服务、邮件、OAuth 和验证码服务均为可选集成，按部署实际启用。示例中的地址、账户和密钥占位值不能用于生产。保护真实配置的文件权限，避免把配置内容放进 Issues、Actions 输出或截图。

资料由部署者提供：

- `data/col/`：整理后的文本语料。
- `data/kb.db` 和向量伴随文件：由语料构建的检索索引。
- `data/state.db`：独立的用户与会话状态。
- `data/source-files/index.json` 与原件目录：原始文件的精确身份、出处与哈希。
- `data/doc_views.json`：可选衍生阅读视图。

为资料记录作者、来源和适用范围。未知许可或游戏版本保持未知，不因为生成阅读页而改写成“已授权”或“已实测”。原件和用户状态不是可以随意重建的缓存；使用备份工具并先在临时目录完成恢复验证。

公开仓库不包含生产语料与数据库。需要在 CI 验证格式时，应创建最小合成样本，不使用私人教程、对话或账号数据。
