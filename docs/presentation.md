# 学习入口与资料发现

首页以教程学习为主，AI助教作为辅助。页面复用已有章节、专题映射、阅读工具和独立Shader展厅，不引入新框架或第二套内容目录。

- 搜索位于首页主入口，支持参数名、工具名和问题关键词。
- 按章节学习、浏览资料库、问AI助教分别说明用途；提问由用户确认后发送。
- 章节与专题只链接现有资料。小型资料库没有预设章节编号时，显示实际章节；没有专题时不显示空专题区。
- 文档库按分类呈现，标题为主、路径为辅；筛选显示可见数量，支持清空和无结果提示。
- 搜索页突出标题与命中摘要，保留经过转义的高亮；输入与示例保持当前分区参数。
- 阅读页继续保留版本和实测状态、原件入口与来源信息，展示改进不改变原件及检索身份。

使用既有浅深主题与蓝色操作强调。页面在1440、375和320px下验证布局、键盘焦点、筛选、搜索、续读与AI入口。浏览器测试使用合成资料；真实资料回放单独在本机验证，不进入公开仓库。
