# 本地演示

这三篇短文由本仓库自造，用于展示目录、阅读和关键词搜索，不包含用户教材、游戏资源、服务器数据或账号。文中的观察记录是虚构例子，不是游戏实测结论。

在仓库根目录安装运行依赖后执行：

```sh
python scripts/create_demo.py
python -m uvicorn app:app --app-dir app --host 127.0.0.1 --port 8000
```

打开 [首页](http://127.0.0.1:8000/)、[演示手册](http://127.0.0.1:8000/manual) 或 [搜索 RimLight](http://127.0.0.1:8000/search?q=RimLight)。使用站内文档库可以阅读全部三篇示例。

生成器只创建被 Git 忽略的 `data/` 和 `config.json`，使用本地 SQLite 全文索引，不请求嵌入服务。应用首次启动会在 `data/` 创建独立状态库。每次生成会随机生成会话密钥，不包含默认管理员密码。

演示配置关闭登录要求，仅供绑定 `127.0.0.1` 的本机阅读。**AI 问答未配置**；邮件、OAuth、Turnstile 和外部模型也未配置。不要把这份演示配置直接用于公网服务。

如果目标中已有 `data/` 或 `config.json`（即使为空），脚本会拒绝运行，且不提供覆盖参数。可以使用 `python scripts/create_demo.py --root <全新临时目录>` 检查生成结果；该选项只重定位数据和配置，不复制应用。若要在该目录启动，需要另有对应 `app/` 副本。已有正式数据的仓库不要执行删除或覆盖来“重置演示”。
