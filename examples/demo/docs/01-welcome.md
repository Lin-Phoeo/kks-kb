# 开始阅读演示

欢迎使用本地知识库演示。这篇文档和旁边的两篇短文全部是为公开仓库编写的示例，没有引用私人教材或在线资料。

## 可以尝试什么

先打开手册目录，进入“本地演示”章节，然后使用文档中的上下一篇导航。也可以打开搜索页，输入 `RimLight`、灯光或记录，观察命中的正文和标题。

## 这份演示的边界

这里展示的是本地阅读与关键词检索。AI 问答未配置，不需要模型账号，也不会为这些阅读操作调用外部嵌入服务。示例不是某个游戏或插件的官方教程。

## 把事实和例子分开

一条有用的技术笔记应说明环境、操作、观察结果和未确认部分。本演示只用短小的虚构内容说明这种结构，不提供游戏参数推荐。
